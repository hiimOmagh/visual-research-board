
# Reference Activation Safety Boundaries — v2.3.0

## allowed

- Turning gathered references into structured metadata
- Creating brief text from source roles and notes
- Grouping references by visual direction, research context, bibliography, trend signal, and risk note
- Preserving source URLs
- Adding rights/access review notes
- Creating activation next steps

## forbidden

- Image generation
- Scraping
- Copyrighted text extraction
- Paywall bypass
- Access circumvention
- Rehosting source media
- Claiming legal permission certainty
- Treating references as owned assets

## metadata

The pack may use metadata such as title, URL, source class, author/creator, publisher, date, access status, rights status, risk level, and notes.

## brief text

Brief text should summarize reference roles and next actions. It must not reproduce large copyrighted passages or imply rights clearance.

## rights/access review

Any publication, reuse, generation workflow, or production use still requires rights/access review.
