
# Book Reference Safety Boundaries — v2.1.7

## allowed

- Searching and storing metadata
- Preserving catalog URLs
- Preserving preview URLs
- Preserving archive URLs
- Preserving ISBN, OCLC, LCCN, DOI, or archive identifiers
- Adding page or chapter notes
- Creating bibliography labels
- Mapping book candidates into BroadReferenceResult

## forbidden

- Copyrighted text extraction
- Full-text scraping
- Paywall bypass
- Access circumvention
- Copying large copyrighted passages
- Claiming legal permission certainty
- Presenting preview access as full access

## metadata

Metadata includes title, author, year, publisher, edition, identifiers, catalog URL, preview URL, archive URL, page/chapter note, and source notes.

## preview

Preview access is not full access. It should be labeled as preview_only unless the source is clearly open access or public domain.

## catalog

Catalog entries are reference anchors. They support verification and bibliography work, but they do not prove rights clearance.
