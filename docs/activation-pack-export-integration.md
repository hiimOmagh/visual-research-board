
# Activation Pack Export Integration — v2.1.1

v2.1.1 connects activation pack preview text to existing text download utilities.

## Purpose

Activation packs should move from preview-only inspection to controlled metadata/brief-text download using the existing export/download helper path.

## Supported export formats

- Markdown
- JSON

## Export content

- activation pack title
- query
- pack type
- summary
- visual direction
- research context
- source roles
- risk/access notes
- activation next steps
- constraints

## Safety boundaries

- Metadata/brief-text export only
- No export system rewrite
- No broad export expansion
- No scraping
- No image generation
- No copyrighted text extraction
- No paywall bypass
- No access circumvention
- No source media rehosting
- No claim of rights clearance

## Product rule

Discovery first. Classification second. Risk/access/licensing labels third. User judgment fourth. Creative or research activation last.

This layer connects structured preview text to existing download utilities only.
