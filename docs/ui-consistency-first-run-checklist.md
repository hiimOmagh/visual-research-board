
# UI Consistency First-Run Checklist — v2.2.0

## Viewports

Review:

- desktop
- mobile

## Required states

Check:

- first-run panel visible
- landing/default state
- empty-state
- first search
- first saved reference
- activation pack
- export preview

## Questions

- Is the first-run panel visible without pushing the primary action too far away?
- Is the primary action still easy to identify?
- Does the panel explain the workflow before the user reaches complex controls?
- Is empty-state guidance still visible and understandable?
- Are activation pack and export preview concepts understandable?
- Are boundary notes clear without dominating the UI?
- Is there any overflow, duplicate spacing, or broken card alignment?

## review outcome

Record desktop, mobile, first-run panel visible, primary action, empty-state, activation pack, export preview, and blocking issues.
