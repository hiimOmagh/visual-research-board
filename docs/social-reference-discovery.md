
# Social Reference Discovery Layer — v2.0.3

v2.0.3 adds public social-reference discovery planning and classification.

## Purpose

Social references can help users explore public discourse, creator context, visual inspiration, platform-specific styles, trend direction, and topic context.

This layer maps public social-reference candidates into the Broad Reference Result Model with `source_class: social_media`.

## Public social-reference scope

Supported planning/classification targets include:

- X/Twitter
- Instagram
- TikTok
- YouTube
- Pinterest
- Reddit
- Facebook public pages
- LinkedIn public pages
- creator sites
- forums

## Safety boundaries

- No private account scraping
- No login bypass
- No hidden API abuse
- No media rehosting
- No claim of private-platform access
- No claim of rights clearance
- No dedicated social provider implementation yet

## Product rule

Discovery first. Classification second. Risk/access/licensing labels third. User judgment fourth. Creative or research activation last.

Social references are context and inspiration objects unless source, access, and rights status are reviewed.
