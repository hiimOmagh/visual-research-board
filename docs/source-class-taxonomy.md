# Source Class Taxonomy — v2.0.2

## Source classes

### web_image

A direct or image-heavy web result.

### web_page

A general web page, article, blog, or reference page.

### social_media

A public social-platform reference such as X/Twitter, Instagram, TikTok, Reddit, Pinterest, Facebook public pages, or similar public-facing platform results.

### book

A book, catalog entry, ISBN metadata record, preview, or bibliographic reference.

### archive

An archive, public collection, institutional record, or preserved source page.

### museum

A museum or cultural collection result.

### stock

A stock, illustrative, or commercial image-library result.

### video

A video, channel, video page, or video-derived reference.

### unknown

A result that cannot be confidently classified yet.

## Rule

Source class is a classification label, not a permission label. Rights and access remain separate metadata.
