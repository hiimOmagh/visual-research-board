# Reference Intelligence Workflow — v2.1.1

## Workflow

### 1. Find

The user searches broadly. The app should not hide useful references merely because rights or access status are unclear.

### 2. Classify

Each useful result can be classified by source role and intended use.

### 3. Understand

Reference intelligence helps the user understand why a result matters:

- What can this be used for?
- What evidence role does it play?
- Is it a visual reference, context anchor, claim support, or generation seed?
- What risk/access labels need review?

### 4. Organize

The user can group references by role, use, source class, and risk/access state.

### 5. Activate

The reference becomes a foundation for:

- research packs
- moodboards
- creative briefs
- visual direction
- generation-ready prompts
- claim/source context

## Boundary

Reference intelligence is a metadata and interpretation layer. It is not legal clearance and does not guarantee source certainty.
