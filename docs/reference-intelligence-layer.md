# Reference Intelligence Layer MVP — v2.1.3

v2.1.3 begins the product-expansion track after the public demo stable release.

## Purpose

Reference Intelligence turns search results into structured, interpretable, usable reference objects.

The result is not the final output. The result is the starting point for exploration, understanding, organization, and creative/research activation.

## Product rule

Discovery first. Classification second. Risk/access/licensing labels third. User judgment fourth. Creative or research activation last.

This layer is not a licensing filter. It does not block broad discovery. It adds context so the user can understand and decide how to use a reference.
