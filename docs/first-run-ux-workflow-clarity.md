
# First-Run UX + Workflow Clarity — v2.1.11

v2.1.11 improves first-run workflow clarity for a new user.

## Goal

A new user should understand the app in under 60 seconds:

1. search for references
2. save useful references to the board
3. review source class, access notes, coverage, and risk
4. build an activation pack
5. preview/export structured Markdown or JSON

## first-run workflow

The intended first-run workflow is:

```text
search → save → review → activation pack → export
```

## what to do next

The primary first-run next action is:

```text
Start with one broad search, save three useful references, then build an activation pack.
```

## empty-state guidance

When the board is empty, the interface should explain:

- try a broad visual or research query
- search can cover web, image, book, social-reference, museum/open-access, and stock/illustrative source classes when available
- save only references that add evidence, style direction, context, or production utility
- build an activation pack after the board has a focused working set

## Boundary copy

The first-run UX must preserve these boundaries:

- no automatic rights clearance
- no private/account-gated scraping
- no paywall bypass
- no source media rehosting
- no claim that every result is verified

## Non-goals

- no new providers
- no scraping
- no image generation
- no export rewrite
- no dependency churn
- no source media rehosting
- no paywall bypass
