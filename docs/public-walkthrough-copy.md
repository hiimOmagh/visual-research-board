# Public Walkthrough Copy — v2.1.5

## public walkthrough copy

### Headline

Build a source-aware visual reference board in minutes.

### Subheadline

Search, save, review, activate, and export references with visible source context and practical production notes.

### Short pitch

Visual Research Board helps creative teams collect reference material, keep source context, flag weak spots, and turn reviewed references into activation-ready notes without pretending that every result is not rights-cleared or automatically verified.

### Workflow copy

#### Search

Start with a topic, visual direction, person, place, event, or scene idea.

#### Save

Keep the strongest reference candidates and preserve source context.

#### Review

Check the reference role, usefulness, source quality, and risk/access notes before using it.

#### Activate

Turn reviewed references into an activation pack for creative direction, prompts, production notes, or planning.

#### Export

Export source-aware evidence and notes for handoff, review, or production planning.

## call to action

Start with a search topic, save the strongest references, review their role, then generate an activation pack.

## Safety copy

This workflow supports human editorial review. It does not guarantee rights clearance, private account access, paywall bypass, or source media rehosting.
