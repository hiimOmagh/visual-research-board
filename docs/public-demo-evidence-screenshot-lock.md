
# Public Demo Evidence + Screenshot Lock — v2.0.5

v2.0.5 locks public demo visual evidence for the stable v2 workflow.

## Objective

Capture hosted demo screenshots that prove the public demo communicates the product workflow clearly.

## Required hosted demo screenshots

- landing/default state
- discovery/board state
- activation pack workflow
- export integration panel
- empty-state behavior
- desktop-width sanity
- mobile-width sanity

## Evidence requirements

Each screenshot should show:

- visible app version or release context when available
- clear public demo state
- no unavailable/fake-live features
- no broken layout
- no hidden primary action
- no overflow on the captured viewport
- workflow clarity for discovery → board → activation → export

## Review questions

- Can a new user understand what to search?
- Can a new user see where results become board items?
- Can a new user identify activation pack workflow steps?
- Can a new user identify export/preview behavior?
- Are risk/access boundaries still visible or discoverable?
- Does the UI avoid implying rights clearance, scraping, generation, or access bypass?

## Non-goals

- no new features
- no provider expansion
- no export rewrite
- no scraping
- no image generation
- no copyrighted text extraction
- no paywall bypass
- no access circumvention
- no source media rehosting

## Acceptance

The release is acceptable when screenshots exist or are explicitly listed for capture, full QA passes, and release docs describe the evidence set.
