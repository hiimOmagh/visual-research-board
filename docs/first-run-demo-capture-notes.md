# First-Run Demo Capture Notes — v2.1.3

## demo capture notes

Use these notes when recording a demo or collecting screenshots for the first-run workflow.

## Target story

Show the workflow:

```text
search -> save -> review -> activation pack -> export
```

## Required viewports

Capture or inspect:

- desktop
- tablet
- mobile

## Capture sequence

1. Open the app in a clean first-run state.
2. Capture the first-run panel before any search.
3. Confirm the primary search action is visible.
4. Run a representative search.
5. Save one useful reference.
6. Review the saved reference.
7. Open or inspect the activation pack.
8. Open or inspect export preview.
9. Confirm boundary notes remain visible or discoverable.

## Screenshot file names

Use:

```text
artifacts/first-run-screenshots/desktop-first-run.png
artifacts/first-run-screenshots/tablet-first-run.png
artifacts/first-run-screenshots/mobile-first-run.png
```

## review outcome

Record:

- desktop: pass/fail
- tablet: pass/fail
- mobile: pass/fail
- first-run panel visible: pass/fail
- primary search action visible: pass/fail
- activation pack clarity: pass/fail
- export preview clarity: pass/fail
- blocking issues
