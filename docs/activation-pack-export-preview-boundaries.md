
# Activation Pack Export Preview Boundaries — v2.1.5

## allowed

- Rendering activation packs as preview text
- Rendering Markdown preview text
- Rendering JSON preview text
- Showing metadata, source roles, risk/access notes, and constraints
- Preserving source URLs
- Preparing for future export design without changing export behavior

## forbidden

- Broad export system rewrite
- File download expansion
- New download behavior
- Scraping
- Image generation
- Copyrighted text extraction
- Paywall bypass
- Access circumvention
- Rehosting source media
- Claiming legal permission certainty

## preview text

Preview text is for inspection before future export workflows. It is not a new publishing or download pipeline.

## metadata

Metadata may include title, source URL, source role, access status, rights status, risk level, and brief notes.

## rights/access review

Preview output still requires rights/access review before publication, reuse, generation workflows, or production use.
