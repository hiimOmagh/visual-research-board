
# Activation Pack Export Preview — v1.9.0

v1.9.0 adds preview-only structured text rendering for activation packs.

## Purpose

Before a future export workflow is expanded, users need to inspect what an activation pack would look like as structured Markdown or JSON. This milestone adds preview rendering only.

## Preview-only formats

- Markdown
- JSON

## Preview contents

- title
- query
- pack type
- summary
- visual direction
- research context
- source roles
- risk/access notes
- activation next steps
- constraints

## Safety boundaries

- No broad export system rewrite
- No file download expansion
- No new download behavior
- No scraping
- No image generation
- No copyrighted text extraction
- No paywall bypass
- No access circumvention
- No claim of rights clearance

## Product rule

Discovery first. Classification second. Risk/access/licensing labels third. User judgment fourth. Creative or research activation last.

This layer previews structured metadata and brief text only.
