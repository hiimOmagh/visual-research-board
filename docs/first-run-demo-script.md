## Demo story

Use this workflow:

```text
search -> save -> review -> activation pack -> export
```

## Narration outline

1. Start from a clean board.
2. Point to the first-run panel.
3. Confirm the primary search action is visible.
4. Search for a representative reference topic.
5. Save a useful reference candidate.
6. Review its source context, role, and risk/access notes.
7. Open the activation pack.
8. Open export preview.
9. Close by explaining boundaries.
