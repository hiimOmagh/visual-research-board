# v2.2.0 — Dependency Audit Resolution + Safe Upgrade Lock

Verification command:

```bash
npm run verify:ci-parity
```

Policy lock:

- forbids `npm audit fix --force`
- blocks high/critical vulnerabilities
- requires `package-lock.json` review after dependency changes
- requires CI parity after dependency changes
- documents noncritical audit findings as safe-upgrade evidence
