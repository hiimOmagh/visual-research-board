
# Activation Pack UI Integration — v2.0.5

v2.0.5 integrates activation packs into the visible board workflow.

## Purpose

Activation packs should be accessible from gathered board references. This milestone adds a UI workflow model and panel that turns selected or full-board references into activation-ready packs.

## Activation-ready workflow

The workflow exposes:

- board mode
- selected-reference mode
- empty state
- review mode
- selected reference count
- available reference count
- guidance notes
- embedded activation pack preview

## Safety boundaries

- No image generation
- No scraping
- No copyrighted text extraction
- No paywall bypass
- No access circumvention
- No export expansion
- No rehosting source media

## Product rule

Discovery first. Classification second. Risk/access/licensing labels third. User judgment fourth. Creative or research activation last.

This UI integration only organizes existing board references into structured metadata and brief text.
