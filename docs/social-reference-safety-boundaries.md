
# Social Reference Safety Boundaries — v1.8.0

## allowed

- Classifying public links as social references
- Preserving source URLs
- Labeling platform restrictions
- Using public social references for context, trend analysis, creator context, or visual inspiration
- Mapping public social-reference candidates into BroadReferenceResult

## forbidden

- Private account scraping
- Login bypass
- Hidden API abuse
- Media rehosting
- Re-uploading platform media as owned content
- Claiming source certainty without review
- Claiming legal permission certainty
- Circumventing platform restrictions

## public links

The layer is designed for public/reference-facing links. If a result requires login, account access, or unavailable private context, it must be labeled as platform-restricted or unknown.

## platform restrictions

Platform restrictions are metadata. They do not automatically make a reference unusable, but they require review before publication, reuse, or generation workflows.
