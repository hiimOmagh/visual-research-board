
# Activation Pack UI Workflow — v2.1.11

## allowed

- Building packs from gathered board references
- Building packs from selected references
- Showing empty states before references exist
- Showing source-role guidance
- Showing risk/access review notes
- Preserving source URLs
- Keeping activation content as metadata and brief text

## forbidden

- Image generation
- Scraping
- Copyrighted text extraction
- Paywall bypass
- Access circumvention
- Export expansion
- Rehosting source media
- Treating references as owned assets

## selection

Selected-reference mode uses selected result IDs when available. If no selection is provided, the full board result set can be used.

## board references

Board references remain the source of truth. The UI integration does not fetch or modify external sources.

## rights/access review

Activation is not clearance. Rights/access review remains required before publication, reuse, generation workflows, or production use.
