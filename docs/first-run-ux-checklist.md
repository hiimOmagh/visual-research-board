
# First-Run UX Checklist — v2.3.0

## Target

A new user should understand the workflow in under 60 seconds.

## Review states

Check these states:

- landing/default state
- empty board
- first useful search
- first saved reference
- review/evidence/risk state
- activation pack
- export preview

## Questions

For each state, ask:

- Does the user know what to do next?
- Is the next action visible?
- Is the difference between search result, saved reference, board item, activation pack, and export clear?
- Are empty-state instructions useful?
- Are source/risk/access boundaries visible or discoverable?
- Does the UI avoid implying automatic rights clearance?
- Does the UI avoid implying scraping or paywall bypass?
- Does the UI avoid implying image generation?

## Acceptance

- The first-run workflow is visible.
- The empty-state guidance is specific.
- The activation pack purpose is understandable.
- Export preview purpose is understandable.
- Boundary copy is clear.
- Existing release checks remain green.

## review outcome

Record:

- desktop review: pass/fail
- mobile review: pass/fail
- first-run clarity: pass/fail
- blocking issues
- follow-up milestone
