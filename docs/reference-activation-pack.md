
# Reference Activation Pack MVP — v2.0.3

v2.0.3 turns gathered references into activation-ready metadata and brief-text packs.

## Purpose

A reference collection is only useful when it can become a structured research, creative, or production brief. This layer groups existing references into source roles, visual direction, research context, risk/access notes, and next steps.

## Pack contents

- summary
- visual direction
- research context
- source roles
- risk/access notes
- activation next steps
- constraints

## Supported pack types

- research brief
- visual direction
- creative brief
- source map
- production notes
- moodboard brief
- claim context pack

## Safety boundaries

- No image generation
- No scraping
- No copyrighted text extraction
- No paywall bypass
- No access circumvention
- No broad export behavior changes
- No claim of rights clearance

## Product rule

Discovery first. Classification second. Risk/access/licensing labels third. User judgment fourth. Creative or research activation last.

Activation packs organize already-gathered references. They do not create, scrape, bypass, or rehost source material.
