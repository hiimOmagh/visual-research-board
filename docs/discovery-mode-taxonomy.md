# Discovery Mode Taxonomy — v2.4.0

## broad

General broad discovery. Includes web/image/archive/museum/stock/video/unknown source classes.

## web

General web-focused discovery. Useful for articles, pages, references, and mixed web results.

## image

Image-first discovery. Useful for direct visual references and image-heavy candidates.

## visual

Visual-reference discovery. Useful for moodboards, creative direction, composition references, and visual source exploration.

## safe_open

Optional lower-risk discovery posture. It asks for open/public-domain/open-license results where possible, but it is not legal clearance.

## Rule

Discovery mode is a retrieval-intent label. It is not a rights guarantee and not a provider promise.
